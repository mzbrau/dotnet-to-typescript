## Prerequisites

- .NET SDK 9.0 or later
- Assemblies compiled with the model types you want to expose

## Install globally

```bash
dotnet tool install dotnet-to-typescript --global
```

## Update to latest

```bash
dotnet tool update dotnet-to-typescript --global
```

## Verify installation

```bash
dotnet-to-typescript --help
```

## Uninstall

```bash
dotnet tool uninstall dotnet-to-typescript --global
```
